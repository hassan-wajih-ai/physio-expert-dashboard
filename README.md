# مركز فيزيو إكسبيرت | لوحة التحكم وإدارة الحجوزات الطبية
## Physio Experts Center - Bookings & Follow-up Dashboard

نظام إداري متكامل لإدارة ومتابعة حجوزات المرضى، تنظيم الغرف الـ 18 وصالة الجيم للتأهيل الطبي والرياضي، واستخراج التقارير والإحصائيات لمركز فيزيو إكسبيرت بالإسكندرية.

---

### ✨ المميزات الرئيسية للنظام:
1. **متابعة حية للمؤشرات الرئيسية (KPIs):**
   - إجمالي الحجوزات، الحالات المؤكدة، قيد الانتظار، والجلسات المكتملة.
   - نسبة إشغال الغرف الـ 18 الفندقية وصالة الجيم الطبي.

2. **تحليلات ورسوم بيانية تفاعلية (Chart.js):**
   - رسم بياني لتوزيع الحجوزات حسب التخصصات الطبية الستة.
   - رسم بياني لحركة المواعيد وتوزيع الجلسات اليومية.

3. **إدارة الحجوزات والجلسات:**
   - جدول تفاعلي يدعم الفلترة الفورية حسب الحالة، التخصص، الطبيب المعالج، أو المكان.
   - بحث فوري بالاسم، رقم الهاتف، أو كود الحجز.
   - تغيير حالة الحجز بنقرة واحدة (مؤكد / مكتمل / ملغي / قيد الانتظار).
   - زر واتساب تفاعلي يفتح محادثة مباشرة مع المريض برسالة تذكير مخصصة.

4. **سجل متابعة تطور المريض (Clinical Follow-up Notes):**
   - تسجيل الملاحظات الطبية لكل جلسة وتوثيق مدى التحسن الحركي والتسكين.

5. **استخراج وتصدير التقارير:**
   - **تصدير Excel / CSV:** بترميز UTF-8 مع BOM لضمان قراءة النصوص العربية دون أي تشويه.
   - **طباعة تقرير طبي PDF:** بتنسيق رسمي مع ترويسة المركز وبيانات الحالات والتواريخ.

6. **المزامنة والتخزين:**
   - تخزين محلي مستمر عبر `localStorage`.
   - قابلية المزامنة مع Google Sheets وWebhooks.

---

### 🚀 تشغيل النظام:
افتح ملف `index.html` في أي متصفح حديث، ولا يتطلب أي إعدادات سيرفر معقدة.
